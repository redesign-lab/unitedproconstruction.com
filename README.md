# United Pro Construction homepage demo

A static, mobile-first homepage redesign for United Pro Construction, based on the information and photography on the existing website. This demo is marked `noindex` and uses HTML, CSS and vanilla JavaScript without a build step.

## Run locally

Serve the repository root with any static server, for example `python3 -m http.server 8000`, then visit the local server. All project paths are relative and compatible with GitHub Pages project sites.

## Deployment

Publish the repository root on GitHub Pages. The original company logo and project photography are referenced from the existing website's Wix CDN because the development environment could not download files from that host. Google Fonts are also externally hosted; connectivity to these services is required for those assets.

Contact details and service descriptions were checked against the existing site. The original site contains inconsistent email spellings and Saturday hours across pages; verify those details before production use.
